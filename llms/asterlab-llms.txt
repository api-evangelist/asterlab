# Aster (Asterlab)

> Aster AI Labs, PBC is a San Francisco based Y Combinator (Spring 2026) public benefit corporation building autonomous research systems that coordinate thousands of AI research agents to automate open-ended scientific discovery. It offers Aster Inference, an OpenAI-compatible inference API serving open-weight models at what it benchmarks as the fastest gpt-oss-120b output speed on GPU (644 tok/s), with zero data retention by default.

## APIs

- [Aster Inference API](https://www.asterlab.ai/inference): OpenAI-compatible inference API. Base URL https://api.asterlab.ai/v1. Models: gpt-oss-120b, gpt-oss-120b-fast, GLM 5.2. Authenticate with an Aster API key (Authorization: Bearer). Works with the OpenAI Python/JS SDKs, LangChain, LiteLLM, Cursor, and the Vercel AI SDK.
